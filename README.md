# The Price Effects of the Delta/Northwest Merger

## Project Overview
This repository contains the data processing pipeline and analysis for the paper *The Price Effects of the Delta/Northwest Merger:
Evidence from a Route-Level Panel*

The project examines how the 2008 airline merger between Delta and Northwest affected consumer prices on routes where both airlines overlapped. I estimate a difference-in-differences model over a route-quarter level panel, using route and quarter fixed effects to absorb time-invariant route characteristics and common shocks. 

I estimate that fares on connecting routes where both Delta and Northwest operated rose 2.6% (95% CI: 1.8-3.3%) relative to comparison routes. Passenger volume fell 2.7% and market concentration rose 938 HHI points. The effect appears at full operational integration, and not at the deal's announcement or close. 

[Read the paper](paper/DL_NW_Merger_Analysis.pdf)

## Data
The data for the project is sourced from the Bureau of Transportation Statistics DB1B Market data, a random 10% sample of U.S. airline ticket records available for free download on the BTS website. Selected period spans from 2006Q1 to 2011Q4, including 24 quarterly files in total. The selected columns from the market data include `Year`, `Quarter`, `Origin`, `Dest`, `TkCarrier`, `Passengers`, `MktFare`, `MktDistance`, `MktCoupons`, `BulkFare`, `TkCarrierChange`, `MktGeoType`, `OriginCityMarketID`, and `DestCityMarketID`. Due to their size, the raw data is gitignored, and must be fetched separately for reproduction. 

## Tools
The main data pipeline for this project is built using pandas, and the econometric models are generated using PyFixest. All event-study plots and trend figures are generated with Matplotlib. Every table and figure is produced by script.

## Reproduction
To reproduce the study, follow these commands.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
# download the 24 DB1B Market files into data/raw/
python -m src.00_build_vocab
python -m src.01_clean_quarter
python -m src.02_build_panel
python -m src.03_define_treatment
python -m src.04_descriptives
python -m src.05_estimate
python -m src.06_make_outputs
python -m src.07_robustness
```

## Repository Structure
The project repository map is as follows
```text
dlnw-merger/
├── config.py                   # every constant parameter
├── requirements.txt            # pinned
├── paper/                      # LaTeX source, references .bib, compiled PDF
├── src/
│   ├── 00_build_vocab.py       # collects airport/carrier codes
│   ├── 01_clean_quarter.py     # raw DB1B to filtered, collapsed quarterly files
│   ├── 02_build_panel.py       # stacks quarters, creates route-quarter panel and carrier shares
│   ├── 03_define_treatment.py  # assigns treated, Control A, and Control B
│   ├── 04_descriptives.py      # Table 1, Figure 1
│   ├── 05_estimate.py          # baseline DiD, Table 2
│   ├── 06_make_outputs.py      # Figure 2
│   └── 07_robustness.py        # Table 3
├── output/                     # generated tables, figures, audit logs
├── data/raw/                   # gitignored — download from transportation statistics
├── data/clean/                 # gitignored — generated by 01
└── data/panels/                # gitignored — generated by 02
```
Note that `config.py` holds every parameter, so a change there will regenerate every number in the paper when the pipeline is re-run.

## Relation to Luo (2014)
Luo (2014) studies the same merger using a differenced cross-sectional design, and found an effect of +2.3% on connecting market fares. This is statistically indistinguishable from the effect I found of +2.6%, and shows that the estimated price increase is robust to different identifying assumptions and control variables.
